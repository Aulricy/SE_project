## 设计范围

平台包含用户与权限、商品管理、预约与交易、交易统计、操作日志五个模块。采用同一Web应用和共享关系数据库的设计，交易在线下付款和交付。

当前交付为设计成果和离线交互原型，真实服务端、数据库持久化、事务与并发控制仍待后续实现。原型演示账号及样例数据不能替代真实身份认证和业务数据。
